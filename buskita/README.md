# Buskita アプリケーションパッケージ

この `buskita` ディレクトリは、**Ryukoku Bus Navi** ウェブアプリケーションのコアとなる Flask アプリケーションパッケージです。

## 概要

アプリケーションの主要なロジック、ルーティング、ビジネスサービス、そしてフロントエンドで利用される静的ファイルやテンプレートが格納されています。プロジェクトのルートディレクトリにある `run.py` から、このパッケージが呼び出されることでアプリケーションが起動します。

## パッケージ構造

```
buskita/
├── __init__.py          # アプリケーションファクトリ
├── routes.py            # URLルーティング定義
├── services/            # ビジネスロジック（API連携、データ処理）
├── static/              # CSS, JavaScript, 画像などの静的ファイル
├── templates/           # HTMLテンプレート (Jinja2)
└── README.md            # このファイル
```

### 主要モジュールの役割

- **`__init__.py`**:
  アプリケーションインスタンスを生成する「アプリケーションファクトリ」パターンを実装しています。設定の読み込みや、バックグラウンドスレッドの起動など、アプリケーションの初期化処理を担当します。

- **`routes.py`**:
  URL のエンドポイント（例: `/`, `/timetable`）と、それに対応するビュー関数を定義しています。ユーザーからのリクエストを適切な処理に振り分ける役割を担います。

- **`services/`**:
  外部のバス会社 API との通信、取得したデータの加工、キャッシュの管理など、アプリケーションのビジネスロジックを実装するモジュールが配置されます。`routes.py` から呼び出され、具体的なデータ処理を行います。

- **`static/`**:
  フロントエンドで使用される `style.css` や、地図表示ライブラリ (Leaflet.js) に関連するファイル、時刻表データ (`timetable.json`) などが格納されています。

- **`templates/`**:
  ユーザーに表示される HTML ページのテンプレートファイルが格納されています。Flask のテンプレートエンジンである Jinja2 を利用して、動的なコンテンツを生成します。

---

このパッケージは、関心事の分離（Separation of Concerns）の原則に基づき、各モジュールが明確な役割を持つように設計されています。これにより、コードの可読性、メンテナンス性、そしてテストの容易性が向上します。
