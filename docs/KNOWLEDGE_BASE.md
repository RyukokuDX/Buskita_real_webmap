# ナレッジベース

このドキュメントは、プロジェクトに関する様々な知見や調査結果を蓄積する場所です。

## 機能要件 達成状況 (2025/09/11 時点)

`docs/01_concept_and_requirements/REQUIREMENTS.md` に記載されている機能要件について、ソースコードベースで達成状況を調査した結果を以下にまとめる。

| ID | 機能名 | 達成状況 | 備考 |
| :--- | :--- | :--- | :--- |
| **F-01** | **リアルタイムバスマップ** | ✅ **実装済み** | `/api/bus_locations` エンドポイントがバスのリアルタイム位置情報を提供しています。 |
| **F-02** | **バス情報の表示** | ✅ **実装済み** | バス位置情報に路線名やIDなどの詳細情報が含まれており、表示可能です。 |
| **F-03** | **主要ランドマークの表示** | ✅ **実装済み** | `/api/landmarks` エンドポイントが大学と駅の位置情報を提供しています。 |
| **F-04** | **遅延情報の表示** | ⚠️ **ほぼ実装済み** | バックエンドでは遅延情報を取得する処理が存在します。フロントエンドでの最終的な表示実装が残っている可能性があります。 |
| **F-05** | **乗車率の可視化** | ⚠️ **ほぼ実装済み** | バックエンドでは混雑度を取得する処理が存在します。フロントエンドでのアイコン色変更などの実装が残っている可能性があります。 |
| **F-06** | **時刻表機能** | ✅ **実装済み** | `/timetable` ページと、時刻表データを提供する `/api/timetable_data` エンドポイントが実装されています。 |
| **F-07** | **接近通知機能** | ❌ **未実装** | Webプッシュ通知に関連するバックエンド処理やAPIエンドポイントは見当たりませんでした。 |
