# 要件定義書: Ryukoku Bus Navi

## 1. 概要

| 項目                 | 内容                                                                                                     |
| :------------------- | :------------------------------------------------------------------------------------------------------- |
| **アプリ名**         | Ryukoku Bus Navi (仮称)                                                                                  |
| **目的**             | 龍谷大学瀬田キャンパスへのバス通学における、不安や不便を解消し、より快適でスマートな通学体験を提供する。 |
| **ターゲット**       | 龍谷大学 瀬田キャンパスに通う学生、及び教職員。                                                          |
| **プラットフォーム** | Web ブラウザ（スマートフォンでの閲覧を主眼に置いたレスポンシブデザイン）                                 |

## 2. 機能要件

### 2.1. 実装済み機能

| ID   | 機能名                 | 実装状況 | 技術詳細                                         |
| ---- | ---------------------- | -------- | ------------------------------------------------ |
| F-01 | リアルタイムバスマップ | ✅ 完了  | Leaflet.js、3 秒間隔更新、複数タイルサーバー対応 |
| F-02 | バス詳細情報表示       | ✅ 完了  | 行き先・遅延・乗客数表示、並列 API 取得          |
| F-03 | ランドマーク表示       | ✅ 完了  | 龍谷大学・JR 瀬田駅、座標直接指定                |
| F-04 | 遅延情報表示           | ✅ 完了  | delayMinutes フィールド使用                      |
| F-05 | 混雑度可視化           | ✅ 完了  | 6 段階色分け、凡例付き                           |
| F-06 | 時刻表機能             | ✅ 完了  | 静的 JSON、カウントダウン、レスポンシブ          |
| F-07 | ダッシュボード         | ✅ 完了  | リアルタイムカウントダウン、スワイプ対応         |
| F-08 | 堅牢性機能             | ✅ 完了  | バックアップ、フォールバック、エラー対応         |
| F-09 | ネットワーク診断       | ✅ 完了  | 外部接続テスト API、VPN 問題切り分け支援         |
| F-10 | 構造化ロギング         | ✅ 完了  | 重要度別ログ、本番環境ファイル出力               |

### 2.2. 将来的な拡張候補

今後の開発で検討可能な機能です。

| ID   | 機能名             | 機能詳細                                                                   | 備考                                          |
| :--- | :----------------- | :------------------------------------------------------------------------- | :-------------------------------------------- |
| F-11 | **接近通知機能**   | ・指定したバス停にバスが近づいたことを検知し、Web プッシュ通知を送信する。 | ・Web Push API 必要<br>・位置情報監視機能必要 |
| F-12 | **履歴・統計機能** | ・バスの運行履歴や遅延統計の表示<br>・混雑パターンの分析表示               | ・データベース必要<br>・データ蓄積機能必要    |

## 3. 非機能要件

| ID    | 要件名             | 詳細                                                                                                                                                        |
| :---- | :----------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| NF-01 | **パフォーマンス** | ・ページの初期表示は 3 秒以内を目指す。<br>・地図の操作（ズーム、移動）がスムーズであること。                                                               |
| NF-02 | **UI/UX**          | ・スマートフォンでの閲覧・操作に最適化された、シンプルで直感的なデザインであること。                                                                        |
| NF-03 | **安定性**         | ・API が一時的に不調な場合でも、アプリが完全に停止することなく、最後に取得した情報を表示するなど、堅牢な動作をすること。（バックアップ/フォールバック機能） |
